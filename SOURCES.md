# Example provenance

The single customer-support classification question follows the Choice pattern:

- TypeSafe's [Choice documentation](https://docs.typesafe.ai/primitives/choice), especially customer-support categories.
- [jkudish/jev-mcp](https://github.com/jkudish/jev-mcp#jev_classify), a community implementation with support-message classification examples.
- TypeSafe's [state documentation](https://docs.typesafe.ai/concepts/state).

Accessed September 21, 2026. The fictional message, category wording, and rendered
image in this repository are original examples. No source code was copied from
the community repository.

Jev's documentation currently describes text-only input. Rendering a message as
an image is this project's Qwen vision adaptation, not a Jev image capability.
No Jev API is called, no API key is needed, and these measurements are not a
Qwen-versus-Jev benchmark. This project is not affiliated with TypeSafe.

Qwen weights are loaded separately from
[Qwen/Qwen3.5-4B](https://huggingface.co/Qwen/Qwen3.5-4B); their license and terms
remain those supplied by the model publisher.
